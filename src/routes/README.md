# Routes

This directory contains the routes of the homepage.

If you want add another page, create a directory which contains `+page.svelte`. The structure should be like this:

```
src/routes/<page_name>/+page.svelte
```

All subpages should include the `<Navbar />` and `<Footer />` to ensure the uniformity.

## alumni
Contains the information of alumni.

## contact
Contact information of CAU CPSS Lab.

## members
List of the current members.

## publications
Publications in the CPSS Lab.

## +page.svelte
The main page.
